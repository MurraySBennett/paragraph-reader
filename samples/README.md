# Example provenance

These examples are bundled for local reading and downloading. Import and notes stay on the reader's device.

| File | Source, rights, and changes |
| --- | --- |
| `rainbow-passage.txt` | Grant Fairbanks, *Voice and Articulation Drillbook*, 2nd ed., p. 127. Transcribed from [IDEA's corrected PDF](https://www.dialectsarchive.com/wp-content/uploads/2015/11/The-Rainbow-Passage.pdf), which identifies the passage as public domain. Line wrapping was removed; wording was retained. |
| `human-machine-teams.tex` | Short methods excerpt transcribed into simple TeX from [Bennett et al., *Human Performance in Competitive and Collaborative Human–Machine Teams*, DOI 10.1111/tops.12683](https://pmc.ncbi.nlm.nih.gov/articles/PMC12093930/), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). The authors' working TeX source informed the selection. HH/HM and DRT abbreviations were expanded, citations and figure references removed, and passages shortened; this is an adapted excerpt. |
| `dutch-auctions.pdf` | Unmodified publisher PDF of Bennett et al., [*Going, going, gone: competitive decision-making in Dutch auctions*](https://doi.org/10.1186/s41235-020-00259-w), *Cognitive Research: Principles and Implications* 5, 62 (2020). [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). |
| `grin-readme.md` | Curated excerpt from [MurraySBennett/grin](https://github.com/MurraySBennett/grin), source commit `874a2e88e9de6dca6727a54274823fa79bc383f7`, [MIT license](https://github.com/MurraySBennett/grin/blob/874a2e88e9de6dca6727a54274823fa79bc383f7/LICENSE). Relative package links were changed to absolute links; the README was shortened. |
| `lion-and-mouse.docx` | Aesop, *The Lion and the Mouse*, as retold by Joseph Jacobs in *The Fables of Aesop* (1894). [Text source](https://www.gutenberg.org/files/28/28-h/28-h.htm); public domain in the United States. The text is repackaged in a Word document without Project Gutenberg branding. Rights elsewhere may differ. |
